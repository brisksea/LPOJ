# 721 进口成本与销售估算

- 作者：admin
- 来源：课程练习
- OJ：LPOJ
- 时间限制：1000 ms
- 内存限制：64 MB
- 权限：公开
- 难度：1
- 分值：10
- 标签：顺序结构|浮点数|格式化输出

## 题目描述

某电商平台进口一批商品，已知单件商品的采购价（外币）、当日汇率、进口关税比例以及预期的利润率。请计算：

1. 单件商品的采购成本（人民币）；
2. 包含关税后的总成本，其中总成本 = 采购成本 × (1 + 关税比例)；
3. 建议销售价，其中建议销售价 = 总成本 × (1 + 利润率)。

所有金额均保留 2 位小数。

## 输入格式

共 3 行：

第 1 行为采购价（外币，浮点数）；第 2 行为外币兑人民币汇率（浮点数）；第 3 行为关税比例与利润率，以空格分隔，例如 `0.15 0.25` 表示 15% 关税和 25% 利润率。

所有输入数据均为非负数。

## 输出格式

共 3 行，格式如下：

`采购成本：XXX.XX元`

`含税总成本：XXX.XX元`

`建议销售价：XXX.XX元`

## 样例输入 1

```text
50.00
7.20
0.10 0.30
```

## 样例输出 1

```text
采购成本：360.00元
含税总成本：396.00元
建议销售价：514.80元
```

## 提示

计算时不要手动添加千位分隔符。

# 722 阶梯物流费用计算

- 作者：admin
- 来源：课程练习
- OJ：LPOJ
- 时间限制：1000 ms
- 内存限制：64 MB
- 权限：公开
- 难度：2
- 分值：10
- 标签：分支结构|浮点数|格式化输出

## 题目描述

某跨境物流公司根据包裹重量（kg）计费，收费标准如下：

| 重量区间 | 收费标准 | 输出档次文字 |
| --- | --- | --- |
| 重量 ≤ 2kg | 固定收费 50 元 | `2kg及以下档` |
| 2kg < 重量 ≤ 10kg | 50 元 + 超过 2kg 部分按 15 元/kg | `2kg-10kg档` |
| 10kg < 重量 ≤ 30kg | 170 元 + 超过 10kg 部分按 12 元/kg | `10kg-30kg档` |
| 重量 > 30kg | 410 元 + 超过 30kg 部分按 10 元/kg | `30kg以上档` |

请输出收费档次及总费用。

## 输入格式

一行，一个大于 0 的浮点数，表示包裹重量（kg）。

## 输出格式

共 2 行，格式如下：

`计费档次：XXX`

`物流总费用：XXX.XX元`

费用保留 2 位小数。

## 样例输入 1

```text
15.5
```

## 样例输出 1

```text
计费档次：10kg-30kg档
物流总费用：236.00元
```

## 提示

区间端点 2、10、30 分别属于其左侧收费档次。

# 723 资产折旧计算

- 作者：admin
- 来源：课程练习
- OJ：LPOJ
- 时间限制：1000 ms
- 内存限制：64 MB
- 权限：公开
- 难度：2
- 分值：15
- 标签：循环结构|浮点数|格式化输出

## 题目描述

某公司购置一台价值为 P 的设备，预计使用 8 年。本题采用固定比例折旧法：每年末的设备余值等于上年末余值乘以 `(1 - 折旧率)`。

请逐年输出第 1 年至第 8 年末的设备余值。计算过程中不进行中间舍入，仅在输出每一行时保留 2 位小数。

## 输入格式

共 2 行：第 1 行为设备原值（人民币，正浮点数）；第 2 行为年折旧率 r，满足 `0 ≤ r ≤ 1`。

## 输出格式

逐年输出 8 行，格式为：`第X年末设备余值：¥XXX.XX`。

## 样例输入 1

```text
50000
0.15
```

## 样例输出 1

```text
第1年末设备余值：¥42500.00
第2年末设备余值：¥36125.00
第3年末设备余值：¥30706.25
第4年末设备余值：¥26100.31
第5年末设备余值：¥22185.27
第6年末设备余值：¥18857.48
第7年末设备余值：¥16028.85
第8年末设备余值：¥13624.53
```

## 提示

原题示例中的第 8 年数值有计算误差；按题目公式计算应为 ¥13624.53。

# 724 每日客流量数据分析

- 作者：admin
- 来源：课程练习
- OJ：LPOJ
- 时间限制：1000 ms
- 内存限制：64 MB
- 权限：公开
- 难度：2
- 分值：15
- 标签：列表|循环结构|数据统计

## 题目描述

给定某零售店一周（周一至周日）的每日客流量，请依次完成以下分析：

1. 计算全周总客流量与日均客流量，日均值只保留整数部分；
2. 输出客流量最高和最低的日期，周一为第 1 天；
3. 输出所有客流量严格低于日均值的日期编号。

若最高值或最低值在多天出现，输出其中日期编号最小的一天。

## 输入格式

一行 7 个非负整数，以空格分隔，依次为周一至周日的客流量。

## 输出格式

共 4 行，格式如下：

`总客流量：XXX 人次，日均：XXX 人次`

`最高日期：第 X 天（XXX 人次）`

`最低日期：第 X 天（XXX 人次）`

`低于日均的日期：X X X`

若没有低于日均的日期，第四行冒号后不输出日期编号。

## 样例输入 1

```text
120 150 110 180 210 320 280
```

## 样例输出 1

```text
总客流量：1370 人次，日均：195 人次
最高日期：第 6 天（320 人次）
最低日期：第 3 天（110 人次）
低于日均的日期：1 2 3 4
```

## 提示

本题输入均为非负整数，日均值等于总客流量除以 7 后向下取整。

# 725 图书库存查询与管理

- 作者：admin
- 来源：课程练习
- OJ：LPOJ
- 时间限制：1000 ms
- 内存限制：64 MB
- 权限：公开
- 难度：2
- 分值：10
- 标签：字典|字符串|模拟

## 题目描述

书店用字典记录每本书的库存数量。请依次完成：

1. 读入 4 本书的初始库存；
2. 办理一次入库：增加指定图书的库存，若图书不存在则新增；
3. 办理一次出库：减少指定图书的库存。若图书不存在，输出 `图书不存在`；若库存不足，输出 `库存不足`；否则完成出库；
4. 输出所有图书及其最终库存。

最终库存按图书加入字典的先后顺序输出：先输出最初的 4 本书，新入库的图书放在最后。失败的出库操作不改变库存。

## 输入格式

共 6 行。前 4 行格式为 `书名 库存量`；第 5 行格式为 `入库 书名 数量`；第 6 行格式为 `出库 书名 数量`。

书名不包含空白字符，库存量和操作数量均为非负整数，最初的 4 个书名互不相同。

## 输出格式

第 1 行输出入库结果 `入库成功`。第 2 行输出出库结果：`出库成功`、`图书不存在` 或 `库存不足`。

之后每行按 `书名：库存` 格式输出所有图书及其最终库存。冒号为中文全角冒号 `：`。

## 样例输入 1

```text
Python基础 10
数据分析 5
机器学习 3
算法导论 8
入库 Python基础 5
出库 数据分析 10
```

## 样例输出 1

```text
入库成功
库存不足
Python基础：15
数据分析：5
机器学习：3
算法导论：8
```

## 提示

当出库数量恰好等于当前库存时，操作成功，最终库存为 0。
