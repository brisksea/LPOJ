# 1001 A+B Problem

- 作者：admin
- 来源：LPOJ
- OJ：LPOJ
- 时间限制：1000 ms
- 内存限制：64 MB
- 权限：私密
- 难度：1
- 分值：100
- 标签：入门|模拟

## 题目描述

输入两个整数，输出它们的和。

## 输入格式

一行两个整数 $a,b$。

## 输出格式

输出一个整数，表示 $a+b$。

## 样例输入 1

```text
1 2
```

## 样例输出 1

```text
3
```

## 提示

$|a|,|b| \le 10^9$。
